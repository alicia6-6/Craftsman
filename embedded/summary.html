01 · 회로설계·전자회로이론

전자회로의 기초: 옴의 법칙과 전력

전기전자공학 과목의 단골 1번 문제 유형입니다. 공식 자체는 쉽지만 단위(m, k, M) 변환에서 실수하는 경우가 많습니다.

쉽게 말하면 전압(V)은 물을 밀어내는 수압, 전류(I)는 실제로 흐르는 물의 양, 저항(R)은 파이프의 굵기(가늘수록 저항 큼)에 비유할 수 있습니다. 파이프가 가늘면(저항↑) 같은 수압에서 물이 적게 흐릅니다(전류↓).
옴의 법칙V = IR전압 = 전류 × 저항
전력(3형태)P = VI = I²R = V²/R상황에 맞는 형태를 골라 계산
키르히호프 전류법칙(KCL)ΣI(들어옴) = ΣI(나감)한 노드에서 전류의 합은 0
키르히호프 전압법칙(KVL)ΣV = 0폐회로 한 바퀴 전압 합은 0

1. 저항의 직렬·병렬 합성

연결합성저항 공식특징
직렬R = R1 + R2 + ⋯저항이 늘수록 전체 저항 증가, 전류는 모든 저항에서 동일
병렬1/R = 1/R1 + 1/R2 + ⋯합성저항은 항상 가장 작은 저항보다 작음, 전압이 모든 저항에서 동일

2. 교류(AC)의 실효값·평균값·최대값 관계 (★계산 문제 단골)

사인파 기준 변환 공식 (암기 필수)

실효값(Vrms) = 최대값(Vm) × 0.707 (= 1/√2)
평균값(Vavg) = 최대값(Vm) × 0.637 (= 2/π)
평균값 = 실효값 × 0.9 (2√2/π ≈ 0.9) — 시험에 실효값→평균값을 바로 물을 때 가장 빠른 치트키
예) 실효값 100V인 교류전압의 평균값 ≈ 100 × 0.9 = 90V

기출 함정 "실효값 100V 교류의 평균값은?"에서 함정 오답은 최대값(141V, =100×√2)이나 0.637을 곱해 64V로 헷갈리는 것입니다. 0.637은 최대값 → 평균값 변환 비율이고, 0.9는 실효값 → 평균값 변환 비율임을 구분하세요.
02 · 회로설계·전자회로이론

다이오드와 정류회로

다이오드는 한쪽 방향으로만 전류를 흘리는 반도체 소자로, 교류(AC)를 직류(DC)로 바꾸는 정류회로의 핵심 부품입니다.

정류 방식다이오드 개수출력 파형특징
반파 정류1개사인파의 절반(한쪽 극성)만 통과효율이 낮고 리플이 큼
전파 정류(브리지)4개(브리지 연결)양쪽 극성 모두 정류하여 맥류로 출력반파보다 효율 높고 리플 작음
  • 평활회로(필터 커패시터): 정류 후 남은 맥동(리플)을 커패시터로 매끄러운 직류에 가깝게 다듬는 회로.
  • 제너 다이오드: 역방향 항복전압을 이용해 일정한 전압을 유지하는 정전압(정전압원) 회로에 사용.
  • 발진기(수정발진기): 수정편(크리스탈)의 압전기 현상을 이용해 안정적인 주파수를 만드는 소자. 수정편이 두꺼울수록 발진 주파수는 낮아짐(반비례)이며, Q(선택도)가 매우 높아 주파수 변경이 어렵다는 점이 특징 — "발진 주파수 변경이 용이하다"는 틀린 설명(기출 오답 포인트).
03 · 회로설계·전자회로이론

트랜지스터 증폭회로 3형식 비교

이미터/베이스/컬렉터를 접지(공통단자)로 삼는 3가지 증폭회로의 특성 비교는 거의 매 회차 출제되는 최다 빈출 영역입니다.

구분입력 임피던스출력 임피던스전압이득주요 용도
이미터 접지(CE)중간중간~높음크다일반 전압 증폭
베이스 접지(CB)매우 낮음매우 높음크다고주파 증폭
컬렉터 접지(CC, 이미터 폴로어)크다낮다≈1 (작다)임피던스 매칭(버퍼)
기출 함정: "컬렉터 접지의 특징으로 틀린 것은?"
컬렉터 접지(CC)는 입력 임피던스가 크고 출력 임피던스가 낮은 임피던스 버퍼 역할이 핵심이며, 전압이득은 거의 1로 작습니다. "전압이득이 크다"는 이미터 접지(CE)의 특징이므로 틀린 설명입니다. 입력·출력 전압의 위상은 동상(0°)입니다.

1. 증폭기 동작 영역과 클래스

  • 차단영역: 베이스 전류가 0에 가까워 트랜지스터가 스위치 OFF 상태.
  • 포화영역: 컬렉터 전류가 더 이상 증가하지 못하는 완전 ON 상태 (스위치 소자로 사용).
  • 활성영역: 입력 신호에 비례해 출력이 선형적으로 변하는 구간 — 증폭기로 사용하려면 반드시 활성영역에서 동작시켜야 함.

2. 부궤환(Negative Feedback) 증폭회로의 특징 (★단골 출제)

부궤환 4대 효과: 이득↓ 안정도↑ 왜율(왜곡)↓ 대역폭(주파수특성)↑ 출력 일부를 반대 극성으로 입력에 되돌려 "이득은 줄지만 나머지는 다 좋아진다"고 암기
기출 함정 "부궤환 증폭회로의 특징으로 적합하지 않은 것은?" 문제에서 "이득이 증가한다"는 명백한 오답입니다. 부궤환은 이득을 감소시키는 대신 안정도·왜율·주파수특성을 개선하는 트레이드오프 회로입니다.
04 · 회로설계·전자회로이론

블록도 → 회로도 → PCB 설계 절차

2026 신출제기준의 "1. 회로설계" 항목은 제품 개발 절차 자체를 묻는 실무형 문제로 강화되었습니다.

표준 설계 절차 (순서 암기)

1. 블록도 작성: 제품 사양서의 기능을 큰 기능 단위(블록)로 나눠 도식화
2. 블록별 회로 설계: 각 블록을 실제 부품·회로로 구체화
3. 블록별 회로 분석 · 시뮬레이션: PSpice 등 시뮬레이션 프로그램으로 동작 검증 후 설계 확정
4. 회로도 설계: 확정된 블록들을 하나의 전체 회로도로 통합
5. PCB 설계: 부품 배치 최적화 → 배선(라우팅) → 제조 데이터 출력

  • PCB 설계 프로그램: OrCAD, Altium Designer, Eagle, KiCad 등 — 회로도(스키매틱)와 PCB 아트워크를 함께 관리.
  • 시뮬레이션 프로그램: PSpice, LTspice 등 — 실제 부품을 조립하기 전에 회로 동작을 소프트웨어로 미리 검증.
  • 최적화 부품 배치: 발열 부품 분리, 신호선 최단화, 노이즈에 민감한 아날로그·디지털 구간 분리가 핵심 원칙.
05 · 컴퓨터구조

CPU의 구성요소와 주요 레지스터

옛 "전자계산기구조" 과목의 핵심으로, 2026년에도 "컴퓨터구조 일반 → 컴퓨터의 구성요소·CPU의 구성"으로 그대로 이어집니다.

쉽게 말하면 CPU는 요리사에 비유할 수 있습니다. 제어장치(CU)는 요리 순서를 지시하는 두뇌, 연산장치(ALU)는 실제로 재료를 썰고 섞는 손, 레지스터는 손이 닿는 범위에 있는 작은 임시 그릇들(재료를 잠깐 올려두는 곳)입니다.
레지스터약어역할
프로그램 카운터PC다음에 실행할 명령어의 주소를 저장
명령어 레지스터IR현재 실행 중인 명령어(연산코드+오퍼랜드)를 저장
메모리 주소 레지스터MAR메모리에 접근할 주소를 저장
메모리 버퍼 레지스터MBR(MDR)메모리에서 읽거나 쓸 데이터를 임시 저장
누산기ACC(Accumulator)산술·논리 연산의 결과를 일시적으로 저장하는 레지스터
범용 레지스터GPR연산 중간값 등 다목적으로 사용
시프트(Shift) 연산 계산 예시

누산기의 10진수 12(2진수 1100)를 왼쪽으로 2번 시프트 → 110000₂ = 48(10진수). 왼쪽 시프트 1회 = ×2이므로 12 × 2² = 48로 빠르게 계산할 수 있습니다.

명령어 실행 사이클

인출(Fetch) → 해독(Decode) → 실행(Execute) → (필요 시) 저장(Store) 순으로 반복되며, 이 전체 과정을 제어장치가 클록에 맞춰 지휘합니다.

06 · 컴퓨터구조

주소지정방식과 명령어 형식

"속도가 가장 빠른 주소지정방식은?" 유형의 단골 문제입니다.

주소지정방식설명속도
즉시(Immediate)오퍼랜드 자체가 데이터 값메모리 접근 없어 가장 빠름
레지스터(Register)오퍼랜드가 레지스터 번호가장 빠름(레지스터는 CPU 내부라 접근 속도 최상)
직접(Direct)오퍼랜드가 실제 데이터의 메모리 주소메모리 1회 접근
간접(Indirect)오퍼랜드가 "주소가 저장된 주소"를 가리킴메모리 2회 이상 접근 → 가장 느림
상대(Relative)명령어 주소(PC) + 변위값 = 유효주소분기(branch) 명령에 자주 사용
기출 함정 "레지스터 주소지정방식"과 "즉시 주소지정방식" 모두 빠르지만, 즉시 방식은 메모리 접근이 전혀 없고 레지스터 방식은 CPU 내부 레지스터에 1회 접근합니다. 기출에서 "속도가 가장 빠른 것"을 물으면 대개 레지스터 방식을 정답으로 처리하는 경우가 많으니 문제의 선택지 구성을 함께 확인하세요.

명령어 형식(오퍼랜드 개수에 따른 분류)

  • 3-주소 명령어: 연산자 2개 + 결과 저장 주소 1개. 명령어 길이가 길지만 프로그램이 짧아짐.
  • 2-주소 명령어: 가장 흔한 범용 CPU 형식. 연산 결과가 오퍼랜드 중 하나에 덮어써짐.
  • 1-주소 명령어: 누산기(ACC)를 암묵적으로 사용.
  • 0-주소 명령어: 스택(Stack) 구조를 사용 — 연산자를 스택에 쌓아두고 후위표기법(Postfix)으로 처리.
07 · 컴퓨터구조

입출력 제어 방식과 DMA

"CPU의 간섭 없이 메모리와 입출력장치 사이에 데이터가 오가는 방식은?" → 정답은 항상 DMA입니다.

방식특징
폴링(Polling)CPU가 주기적으로 장치 상태를 직접 확인 — CPU 자원을 많이 소모
인터럽트(Interrupt)장치가 준비되면 CPU에 신호를 보내 처리를 요청 — 폴링보다 효율적
DMA(Direct Memory Access)CPU의 개입/간섭 없이 메모리와 입출력장치가 직접 데이터를 주고받음 — 대량 데이터 전송(디스크 등)에 효율적
채널(Channel) 방식입출력 전용 프로세서가 CPU 대신 입출력을 전담 제어
  • 일괄처리(Batch Processing) 시스템: 데이터를 일정 시간/양만큼 모았다가 한 번에 처리하는 방식.
  • 바코드를 대체하는 무선인식 기술: RFID — 계산대에서 물품을 일일이 읽지 않아도 태그를 인식해 자동으로 처리(쇼핑카트 자동 계산, 물류·유가증권 위조방지 등에 활용).

12 · 프로그래밍언어 활용

구조적 프로그래밍(C 언어 기초)

옛 "프로그래밍일반" 과목의 핵심이 그대로 이어지는 영역입니다. C 언어의 기본 문법과 소프트웨어 개발 절차 용어를 정리합니다.

용어역할
컴파일러(Compiler)고급언어 원시 프로그램 전체를 한 번에 기계어로 번역
어셈블러(Assembler)어셈블리어를 기계어로 번역
인터프리터(Interpreter)한 줄씩 해석하며 즉시 실행(번역본 저장 안 함)
로더(Loader)목적 프로그램을 메모리에 적재 — 할당(Allocation)·연결(Linking)·재배치(Relocation)·적재(Loading) 4대 기능
링커(Linker)여러 목적 파일과 라이브러리를 하나의 실행 파일로 연결
기출 함정: "로더의 역할이 아닌 것은?"
로더의 4대 기능(할당·연결·재배치·적재) 이외의 것(예: 원시코드 번역, 문법 오류 검사 등 컴파일러의 역할)이 오답 선택지로 자주 나옵니다.
  • 순서도(Flowchart): 프로그램 논리를 도형으로 표현 — 언어에 관계없이 사용법이 동일(오답 함정: "언어에 따라 순서도 사용법이 다르다"는 틀린 설명).
  • BNF(Backus-Naur Form) 표기법: 프로그래밍 언어의 문법을 정의하는 메타언어. ::= 기호가 "정의"를 의미.
  • 운영체제 스케줄링 목표: 처리량(Throughput, 단위시간당 처리량) ↑ · 응답시간(Turnaround time) ↓ · 신뢰성(Reliability) ↑ · 가용성(Availability) ↑.
13 · 프로그래밍언어 활용 ★최신개정

객체지향 프로그래밍(OOP) 기초

2026년 새 출제기준에서 처음으로 명시된 영역입니다. 과거 기출에는 전혀 없었으므로 기본 개념부터 확실히 잡아야 합니다.

쉽게 말하면 구조적 프로그래밍이 "순서대로 할 일을 나열한 요리 레시피"라면, 객체지향 프로그래밍은 "각자 자기 역할을 아는 요리사(객체)들을 고용해서, 필요할 때 서로에게 일을 시키는" 방식입니다.

객체지향 4대 특성 (★반드시 암기)

특성의미
캡슐화(Encapsulation)데이터(속성)와 메서드(기능)를 하나로 묶고, 내부 구현을 외부로부터 은닉
상속(Inheritance)기존 클래스(부모)의 속성·기능을 새 클래스(자식)가 물려받아 재사용
다형성(Polymorphism)같은 이름의 메서드가 객체(클래스)에 따라 다르게 동작(오버라이딩/오버로딩)
추상화(Abstraction)공통 특성만 뽑아 클래스로 일반화 — 세부 구현은 감춤
  • 클래스(Class): 객체를 만들기 위한 설계도(틀).
  • 객체(Object)/인스턴스: 클래스로부터 실제로 생성된 실체.
  • 생성자(Constructor): 객체가 생성될 때 자동으로 호출되어 초기화를 수행하는 특수 메서드.
  • 대표 객체지향 언어: C++, Java, Python 등 — 임베디드 분야에서는 C++가 대표적으로 사용됨.
예상 출제 포인트 "상속과 캡슐화의 차이", "다형성의 예시로 옳은 것" 유형의 개념 구분 문제가 유력합니다. 구조적 프로그래밍(절차 중심) vs 객체지향(데이터+기능을 객체로 묶음)의 근본적 차이를 문장으로 설명할 수 있도록 준비하세요.
14 · 시스템소프트웨어 펌웨어구현 ★최신개정

운영체제의 종류와 마이크로프로세서 구조

과거 기출에는 전혀 없던 완전 신설 영역입니다. "개발도구 파악" 세부항목의 핵심으로, 임베디드 시스템 개발에 실제로 필요한 배경지식입니다.

1. 운영체제의 종류

구분특징예시
범용 OS다양한 응용프로그램을 범용으로 지원, 응답시간 보장이 목표가 아님Windows, 일반 Linux 배포판, macOS
임베디드 OS특정 하드웨어·목적에 맞춰 경량화된 OS임베디드 리눅스, Android(임베디드 응용)
RTOS(실시간 운영체제)정해진 시간 안에 반드시 응답을 보장(결정론적 처리) — 우선순위 기반 선점형 스케줄링FreeRTOS, VxWorks, RTLinux, QNX
쉽게 말하면 일반 OS는 "최대한 빨리 처리하면 좋은 것"이지만, RTOS는 "느려도 안 되고 빨라도 안 되고, 약속한 시간(데드라인) 안에 정확히 처리하는 것"이 생명입니다. 자동차 에어백처럼 "0.03초 안에 반드시 터져야 하는" 시스템에 RTOS가 쓰입니다.

2. 마이크로프로세서의 구조

  • CISC(Complex Instruction Set Computer): 복잡하고 다양한 명령어 지원, 명령어 길이가 가변적 (예: x86 계열).
  • RISC(Reduced Instruction Set Computer): 명령어 종류를 단순화·고정길이로 만들어 처리 속도 최적화 — 임베디드 시스템에서 널리 사용(예: ARM Cortex-M 계열).
  • 비트 폭: 8비트(초소형 제어) → 16비트 → 32비트(현재 임베디드 주류, ARM Cortex-M) 순으로 처리 성능이 향상.
예상 출제 포인트 "RTOS의 특징으로 옳은 것은?"에서 "평균 응답시간이 가장 빠른 것이 목표다"는 함정 오답입니다. RTOS의 핵심 목표는 평균 속도가 아니라 최악의 경우에도 데드라인을 지키는 것(결정론적 응답)입니다.
15 · 시스템소프트웨어 펌웨어구현 ★최신개정

펌웨어 개발도구와 테스트 절차

임베디드기능사라는 종목명 자체가 바로 이 영역(펌웨어 구현)에서 왔습니다. 개발도구 종류와 단위→기능→통합 테스트 순서를 정리합니다.

1. 펌웨어 개발도구

도구역할
크로스컴파일러(Cross Compiler)개발 PC(x86)에서, 타겟 마이크로프로세서(ARM 등)와 다른 아키텍처용 실행 파일을 만들어내는 컴파일러
디버깅 장비(In-Circuit Debugger)실제 타겟 보드에서 코드를 한 줄씩 실행하며 레지스터·메모리 상태를 확인
에뮬레이터(Emulator)실제 하드웨어 없이 타겟 프로세서의 동작을 소프트웨어로 모의 실행
롬라이터(ROM Writer)완성된 펌웨어 바이너리를 실제 메모리 칩(ROM/플래시)에 기록
통합개발환경(IDE)에디터·컴파일러·디버거를 하나로 묶은 개발 환경
펌웨어 개발 절차 흐름

1. 마이크로프로세서 결정 → 맞는 크로스컴파일러·디버깅 장비 준비
2. 통합개발환경(IDE) 구축
3. 롬라이터·에뮬레이터로 프로그램을 타겟에 입력
4. 테스트 결과에 따라 펌웨어 개선(반복)

2. 펌웨어 테스트 3단계 (★순서 암기)

단위 테스트 → 기능 테스트 → 통합 테스트 작은 단위에서 큰 단위 순으로 검증 범위가 확대됨
단계검증 대상
단위 테스트(Unit Test)펌웨어 규격서 기준으로 모듈(함수) 하나하나가 정상 동작하는지 개별 검증
기능 테스트(Functional Test)구현된 기능이 요구사항(규격서)대로 동작하는지 검증
통합 테스트(Integration Test)여러 모듈을 합쳤을 때 모듈 간 인터페이스가 올바르게 맞물려 동작하는지 검증
예상 출제 포인트 "모듈 간 인터페이스를 검증하는 테스트는?" → 통합 테스트. "개별 함수의 실행 여부를 모듈별로 테스트하는 것은?" → 단위 테스트. 단계별 검증 "대상"의 크기(모듈 하나 vs 여러 모듈의 연결)로 구분하는 것이 핵심입니다.
16 · LAST CHECK

시험장 들어가기 전 마지막 10분 초압축 암기장

헷갈리기 쉬운 공식·순서·비율을 한눈에 최종 점검하세요.

교류 변환 비율

실효값 = 최대값 × 0.707
평균값 = 최대값 × 0.637
평균값 = 실효값 × 0.9
최대값 = 실효값 × 1.414(√2)

3단자 증폭회로 비교

CE(이미터접지): 이득 큼
CB(베이스접지): 고주파용
CC(컬렉터접지): 이득≈1,
입력Z 큼·출력Z 작음(버퍼)

부궤환 효과

이득 ↓
안정도 ↑
왜율(왜곡) ↓
대역폭(주파수특성) ↑

JK 플립플롭

00: 불변
01: Reset(Q=0)
10: Set(Q=1)
11: Toggle(반전)

드모르간 법칙

(AB)' = A' + B'
(A+B)' = A'B'
카르노맵 순서:
조건→진리표→맵→식→게이트

주소지정 속도

빠름: 즉시 · 레지스터
중간: 직접
느림: 간접(2회 이상 접근)
0-주소 명령어 = 스택 구조

코드 특성 구분

자기보수: 3초과코드
인접코드(1비트차): 그레이코드
오류 검출+정정: 해밍코드
음수표현 표준: 2의 보수

★신설 영역 핵심어

RTOS = 결정론적 응답시간
RISC = 임베디드 주류
테스트 순서: 단위→기능→통합
OOP 4대특성: 캡슐화·상속·
다형성·추상화
