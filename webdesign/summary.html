03 · 디자인구성요소설계

디자인의 원리와 조건

디자인 일반 과목의 최다 빈출 영역으로, 지금도 그대로 출제됩니다.

디자인 원리의미
통일(Unity)전체 디자인 요소가 하나로 조화롭게 느껴지는 것
균형(Balance)시각적 무게감의 안정 (대칭/비대칭 균형)
비례(Proportion)부분과 부분, 부분과 전체 사이의 크기 비율 (황금비 등)
강조(Emphasis)특정 부분을 시각적으로 두드러지게 하는 것
율동/리듬(Rhythm)반복·점증 등으로 시각적 움직임을 느끼게 하는 것
대비/조화(Contrast/Harmony)차이를 통한 강조 / 유사함을 통한 통일감
디자인의 4대 조건

합목적성(실용성, 목적에 맞는 기능) · 심미성(아름다움) · 독창성(창의성, 개성) · 경제성(효율적 비용)
"디자인의 조건 중 합목적성에 해당하는 것은?" → 항상 실용적 기능/목적 부합 관련 선택지가 정답

03 · 디자인구성요소설계

착시(Optical Illusion)와 형태 지각

  • 착시: 실제 형태·크기·색과 다르게 인지되는 시각적 오류 현상 (예: 같은 길이의 선이 화살표 방향에 따라 다르게 보이는 뮐러라이어 착시).
  • 게슈탈트(형태) 원리: 근접성(가까운 요소를 하나로 인식), 유사성(비슷한 것을 하나로 묶어 인식), 폐쇄성(불완전한 형태를 완전한 형태로 인식), 연속성(흐름을 따라 인식).
  • 질감(Texture): 시각적 질감(눈으로만 느끼는 표면느낌)과 촉각적 질감(실제 만졌을 때의 표면느낌)으로 구분.
05 · 조색

색의 3속성과 색 지각의 3요소

색의 3속성의미
색상(Hue)빨강, 파랑 등 색 그 자체의 종류
명도(Value/Lightness)색의 밝고 어두운 정도
채도(Chroma/Saturation)색의 선명하고 탁한 정도(순수한 정도)
  • 색 지각(색 자각)의 3요소: 광원(빛) · 물체 · 눈(관찰자) — 이 세 가지가 모두 있어야 색을 인지할 수 있음.
  • 무채색: 색상과 채도가 없고 명도만 있는 색 (흰색·회색·검은색).
05 · 조색

색의 대비와 배색 조화

대비 종류현상
색상대비서로 다른 색상이 인접할 때 색상 차이가 더 크게 느껴짐
명도대비명도가 다른 색이 인접할 때 명도 차이가 더 크게 느껴짐
채도대비채도가 다른 색이 인접할 때 채도 차이가 더 크게 느껴짐
보색대비색상환에서 정반대(보색)에 위치한 색끼리 인접할 때 서로 뚜렷하고 강하게 보임
동시대비두 가지 이상의 색을 동시에 볼 때 일어나는 대비
연속대비한 색을 본 뒤 다른 색을 보았을 때 시간차를 두고 일어나는 대비
동일 색상의 명도 단계적 배색 = 그러데이션(Gradation) 조화 하나의 색상에 여러 명도를 단계적으로 동시에 배색해 얻는 조화
05 · 조색

먼셀(Munsell) 표색계와 색체계

  • 먼셀 표색계: 색상(Hue)·명도(Value)·채도(Chroma) 순으로 HV/C 형식 표기 (예: 5R 4/14). 한국산업표준(KS)의 색채 교육 기준.
  • 색상환(Color Circle): 먼셀은 10가지 기본색(R,YR,Y,GY,G,BG,B,PB,P,RP)을 원형으로 배치.
  • PCCS 색체계: 일본색채연구소가 개발, 톤(Tone) 중심의 색채계획에 특화된 색체계.
05 · 조색 ★최신개정 강화

가법혼합과 감법혼합

혼합 방식원리예시
가법혼합(Additive)색광을 더할수록 밝아짐 → 모두 더하면 흰색(백색광)RGB(빛의 3원색), 모니터·TV 화면
감법혼합(Subtractive)색료를 더할수록 어두워짐 → 모두 섞으면 검정에 가까움CMY(색료의 3원색), 인쇄·물감
기출 함정
"모니터 화면의 색 표현 방식은?" → 가법혼합(RGB). "인쇄물의 색 표현 방식은?" → 감법혼합(CMYK). 웹디자이너는 항상 RGB(가법혼합) 기준으로 작업한다는 점을 기억하세요.
06 · 배색 ★최신개정 강화

배색 형식과 색채 계획

  • 동일색 배색: 같은 색상, 명도·채도만 다르게 — 통일감 있고 안정적.
  • 유사색 배색: 색상환에서 가까운 색끼리 — 자연스럽고 조화로움.
  • 대조색(반대색) 배색: 색상환에서 먼 색끼리 — 강렬하고 개성있는 느낌.
  • 톤(Tone) 배색: 같은 톤(명도·채도 조합)의 색끼리 배색 — 차분하고 정돈된 느낌.

색의 심리적 작용: 따뜻한 색(빨강·주황)은 식욕을 돋우고 활동적인 느낌, 차가운 색(파랑·초록)은 안정·신뢰의 느낌을 줍니다. "제과점 홈페이지에 적합한 색채 계획" 같은 문제는 항상 따뜻한 색 계열을 정답으로 유도합니다.

01·02 · 프로토타입 기초데이터·제작 ★최신개정

UX(User Experience)와 프로토타입

2025년 새 출제기준의 핵심 신설 영역입니다. 과거 기출에는 전혀 없었으므로 정의부터 확실히 잡아야 합니다.

용어의미
UX(사용자 경험)사용자가 제품·서비스를 이용하며 느끼는 전체적인 경험·만족도
UI(사용자 인터페이스)사용자가 실제로 조작하는 화면·버튼 등 접점 요소
기출 함정: 로우파이 vs 하이파이 프로토타입
로우파이(Low-fidelity) 프로토타입은 종이 스케치처럼 빠르고 저렴하게 초기 아이디어를 검증하는 용도이고, 하이파이(High-fidelity) 프로토타입은 실제 색상·인터랙션까지 반영해 완성품과 유사하게 만들어 후반 검증에 사용합니다. "빠른 초기 검증"이 나오면 로우파이가 정답입니다.

프로토타입의 목적: 실제 개발에 들어가기 전, 저비용으로 아이디어를 시각화하고 사용성 문제를 미리 발견하기 위함입니다.

03 · 스토리보드 설계·제작 ★최신개정

와이어프레임과 스토리보드

완성도 순서: 와이어프레임 < 목업(Mockup) < 프로토타입 뼈대만(레이아웃) → 색상/디자인 입힘 → 실제 동작(인터랙션)까지
  • 와이어프레임(Wireframe): 색상·디자인 요소를 배제하고 화면의 배치와 기능(레이아웃)만 뼈대로 표현한 설계도.
  • 목업(Mockup): 와이어프레임에 실제 색상·이미지 등 시각 디자인을 입힌 정적인 시안.
  • 스토리보드(Storyboard): 화면 간의 전환·흐름(Flow)과 인터랙션을 순서대로 표현한 설계 문서.

01 · 저작권 ★최신개정

저작권과 CCL 라이선스

  • 저작인격권: 저작자의 명예·인격을 보호하는 권리 (공표권·성명표시권·동일성유지권) — 타인에게 양도 불가.
  • 저작재산권: 저작물을 경제적으로 이용할 권리 (복제권·배포권 등) — 양도·이용허락 가능.
CCL(Creative Commons License) 4대 구성요소

저작자표시(BY): 저작자를 반드시 표시
비영리(NC): 영리 목적으로 이용 금지
변경금지(ND): 원저작물을 변경하지 않고 그대로만 이용
동일조건변경허락(SA): 변경 시 원저작물과 동일한 라이선스로 배포

웹디자인 프로세스 순서

1. 프로젝트 기획(목표·타겟 설정) → 2. 정보설계(IA) → 3. 스토리보드/와이어프레임 → 4. 디자인 시안 제작 → 5. 퍼블리싱/구현 → 6. 테스트 및 배포

타이포그래피(Typography): 글자를 활용한 디자인 — 가독성(읽기 쉬움)과 판독성(빠르게 인지되는 정도)을 모두 고려해야 하며, 본문은 가독성을, 제목/로고는 판독성·심미성을 더 중시하는 경향이 있습니다.

04 · 구현 및 응용

인터넷·웹 기초 지식

  • 방화벽(Firewall): 내부·외부 네트워크를 격리해 인터넷 보안 위협을 차단하는 시스템.
  • 이메일 송신 프로토콜: SMTP (수신은 POP3/IMAP).
  • TCP/IP 4계층: 네트워크 접근 계층 - 인터넷 계층 - 전송 계층 - 응용 계층.
  • 웹브라우저의 기본 기능: HTML 렌더링, 북마크, 히스토리 관리, 쿠키/캐시 관리 등 (프로그램 코드 편집 기능은 포함 안 됨).
