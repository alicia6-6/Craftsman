05 · 네트워크 프로토콜 분석

LAN·이더넷 표준

  • LAN 특징: 좁은 지역(구내), 높은 전송속도, 낮은 에러율, 사설 소유·관리.
  • LAN 토폴로지: 버스형(공통 회선 공유), 스타형(중앙 허브/스위치 경유, 장애 격리 용이), 링형(순환 구조), 망형(모든 노드가 서로 직접 연결, 신뢰성 최고).
  • 10-Base-T: "10"은 전송속도 10Mbps, "Base"는 베이스밴드 방식, "T"는 UTP 케이블(Twisted pair)을 의미.
  • Fast Ethernet / 이더넷: 100Mbps 이더넷 표준. CSMA/CD 방식으로 매체 접근을 제어(충돌 감지 후 재전송).
망형(Mesh) 네트워크 회선 수 계산

단말기 n개를 모두 망형으로 연결할 때 필요한 최소 회선 수 = n(n-1)/2
예) 단말기 12개 → 12×11/2 = 66회선

스위치·라우터 기본 명령어(Cisco IOS)

2026년 완전 신설된 실무형 영역입니다. Cisco IOS 표준 명령어 체계로 정리합니다.

모드프롬프트진입 명령
사용자 모드Router>로그인 직후 기본 상태
특권 모드Router#enable
전역 설정 모드Router(config)#configure terminal
인터페이스 설정 모드Router(config-if)#interface [인터페이스명]
  • hostname [이름]: 장비의 호스트명(장비이름) 설정 (전역 설정 모드)
  • ip address [IP] [서브넷마스크]: 인터페이스에 IP 주소 부여 (인터페이스 설정 모드)
  • no shutdown: 기본적으로 비활성화(shutdown) 상태인 인터페이스를 활성화
  • show running-config: 현재 메모리(RAM)에 적용 중인 구성정보 확인
  • copy running-config startup-config (또는 write memory): 현재 설정을 NVRAM에 저장해 재부팅 후에도 유지
기출 함정: L2 스위치 vs L3 스위치
L2 스위치는 MAC 주소를 학습해 데이터링크 계층에서 프레임을 전달하는 반면, L3 스위치(=라우터 기능 겸용)는 IP 주소 기반으로 네트워크 계층에서 라우팅까지 수행할 수 있습니다.

라우팅 프로토콜: 정적·RIP·OSPF·EIGRP

구분특징
정적 라우팅(Static)관리자가 직접 경로를 수동 설정. 소규모망에 적합, 변경 시 수작업 필요
RIP거리벡터 방식, 홉 카운트(최대 15홉)로 최적 경로 결정, 소규모망용, 수렴 느림
OSPF링크상태 방식, 대규모망에 적합, 수렴 빠름, 대역폭 등 종합 비용(Cost) 기준
EIGRPCisco 독자 개발, 거리벡터+링크상태 혼합형(하이브리드), 빠른 수렴

이중화(Redundancy)의 목적은 단일 장애점(Single Point of Failure)을 제거해 한 장비·경로가 고장나도 통신이 끊기지 않게 하는 것입니다. HSRP(Cisco 독자)·VRRP(표준)는 여러 라우터를 하나의 가상 IP·가상 라우터처럼 묶어, 주(Active) 라우터 장애 시 대기(Standby) 라우터가 즉시 대체하는 프로토콜입니다.

01 · L2·L3 스위치 구축 ★최신개정

이중화(Redundancy) 프로토콜

  • HSRP(Hot Standby Router Protocol): Cisco 독자 프로토콜, 하나의 가상 IP를 Active/Standby 라우터가 공유.
  • VRRP(Virtual Router Redundancy Protocol): 표준 프로토콜(RFC), 여러 벤더 장비 간 호환 가능.
  • 이중화의 핵심 목적은 가용성(Availability) 향상 — 장애 시에도 서비스가 끊기지 않도록 하는 것입니다.

01·02 · 스위치 구축/보안관리 ★최신개정

VLAN·ACL·NAT 기본 구성

기술목적
VLAN하나의 물리적 스위치를 여러 개의 논리적 네트워크로 분리 — 브로드캐스트 도메인 축소, 보안·관리 용이
ACL(Access Control List)지정된 규칙에 따라 특정 트래픽(IP·포트 등)을 허용/차단
NAT(Network Address Translation)사설 IP ↔ 공인 IP를 변환 — 사설 IP 주소를 외부 인터넷과 통신 가능하게 해줌
  • 트렁크(Trunk) 포트: 여러 VLAN의 트래픽을 하나의 링크로 동시에 전달하는 스위치 간 연결 포트.
  • Standard ACL: 출발지 IP만 검사. Extended ACL: 출발지·목적지 IP, 포트, 프로토콜까지 세밀하게 검사.
  • PAT(Port Address Translation): 하나의 공인 IP를 포트 번호로 구분해 여러 내부 호스트가 동시에 공유(NAT Overload).

04 · 네트워크 운영관리 ★최신개정

네트워크 트래픽·NMS 운용

  • 대역폭(Bandwidth): 단위 시간당 전송 가능한 최대 데이터량 (이론적 최대치). 처리량(Throughput)은 실제로 전송된 양(대역폭보다 항상 작거나 같음).
  • NMS(Network Management System): 네트워크 장비 상태를 중앙에서 모니터링·관리하는 시스템.
  • SNMP(Simple Network Management Protocol): NMS가 장비 상태 정보를 수집하는 데 사용하는 표준 프로토콜.

07 · 서버운용 ★최신개정

서버 가상화와 클라우드 플랫폼

  • 하이퍼바이저: 하나의 물리 서버에서 여러 가상머신(VM)을 생성·관리하는 소프트웨어 (예: VMware ESXi, Hyper-V, KVM).
  • Type 1(Bare-metal): 하드웨어에 직접 설치 (ESXi 등). Type 2(Hosted): 기존 OS 위에 설치되어 실행 (VirtualBox 등).
클라우드 서비스 모델제공 범위
IaaS가상 서버·스토리지·네트워크 등 인프라만 제공 (사용자가 OS부터 설치)
PaaSOS·미들웨어까지 제공, 개발 플랫폼 환경 제공 (사용자는 애플리케이션만 개발)
SaaS완성된 소프트웨어(응용프로그램) 자체를 서비스로 제공 (예: 웹메일, 오피스365)

배포 모델: 퍼블릭 클라우드(불특정 다수가 공유), 프라이빗 클라우드(단일 조직 전용), 하이브리드 클라우드(둘을 혼합).

02 · 네트워크 보안관리

방화벽·보안위협·IDS

  • 방화벽(Firewall): 내부 네트워크와 외부 네트워크 사이에서 정해진 규칙에 따라 접속을 허용/차단하는 장치.
  • IDS(Intrusion Detection System): 침입 행위를 탐지하는 시스템 (차단은 하지 않음 — 차단까지 하면 IPS).
  • 백도어(Trapdoor): 설계자가 유지보수 편의를 위해 고의로 만들어 둔 보안 우회 통로.
  • 보안 3요소: 관리적 보안(정책·규정·교육) · 물리적 보안(출입통제·시설보호) · 기술적 보안(방화벽·암호화·인증).
